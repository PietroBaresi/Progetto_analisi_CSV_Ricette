# Progetto_analisi_CSV_Ricette
In questa repository sarà presente il progetto sulle ricette 2026-27
 
<h1>Com'è fatto il file:</h1>
<p>Prima di procedere con lo sviluppo degli algoritmi di analisi dei dati, è necessario definire la struttura del file CSV. </p>
<h1>Domande chiave
<h3>Qual è il separatore? La prima riga è l'intestazione?</h3>
<p> Il separatore principale è la virgola.
Sì, la prima riga è l'intestazione. Contiene i nomi dei campi.
</p>
<h3>Quante colonne? Quali vi servono per le domande?</h3>
<p> Ci sono 17 colonne.
Per le domande ci servono solo 4 di queste colonne: lo Stato, le calorie, il voto medio, il tempo totale.
</p>
<h3>Trovate almeno un valore mancante o strano. Com'è scritto?</h3>
<p>Sì troviamo dei valori strani, per esempio NA che il valore manca.
Alcune ricette hanno come tempo 0 che significa che è un dato mancante.
</p>
<h3>Quali colonne sono numeri? Hanno il punto o la virgola?</h3>
<p> 11 colonne sono numeriche.
Come separatore usano il punto.
</p>
